# Web Crawler UI

This project is a web user interface that allows users to input questions and receive information from the internet anonymously, leveraging web crawling capabilities.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have Python and pip installed on your machine.

### Installing

1.  Clone the repository.
2.  Navigate to the project directory.
3.  Install the dependencies:
    ```
    pip install Flask
    ```

### Running the application

1.  Run the Flask application:
    ```
    python main.py
    ```
2.  Open your browser and navigate to `http://127.0.0.1:8080`.

You should see the Web Crawler UI in your browser. You can type a question in the search bar and click the "Search" button to see mock results.
